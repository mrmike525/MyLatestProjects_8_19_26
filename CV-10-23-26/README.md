# Michael Lange — One-page React CV

A professional, responsive, print-friendly single-page résumé built with React and CSS. No icon library, UI framework, or API key needed.

## Run

1. Open this folder in VS Code.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local Vite URL shown in the terminal.
5. Click **Print / Save as PDF** and select a PDF destination. Print at 100% scale on US Letter; enable background graphics if your browser asks.

## Customize

- Update your content, skills, and project descriptions in `src/App.jsx`.
- Adjust typography and colors in `src/App.css`.
- The Space Travel project is labeled **In progress** because its completion was not confirmed.
- The LinkedIn URL and contact details come from an earlier résumé you provided; verify them before publishing.
- Add direct project links once you have finished and verified them.
- The PDF preview supplied separately reflects the same content/design as this React component.

This résumé distinguishes personal programming projects from professional experience, and does not claim proficiency in Node.js, TypeScript, or PostgreSQL. TypeScript is listed as continuing study.
